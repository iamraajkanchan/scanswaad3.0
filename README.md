# ScanSwaad 3.0

### 🧾 Milega Swaad QR Scan Ke Baad

**ScanSwaad** is a modern web solution that transforms traditional restaurant menus into sleek, digital QR-code menus. Designed for Indian restaurants with a global standard in mind, ScanSwaad helps hotels manage their menu and customer experience better — all with just one scan.

---

## 🚀 Features

- 🍽️ **Digital Menu Management** – Create, update, and categorize your restaurant's menu.
- 📲 **QR Code Generation** – Generate table-wise QR codes for seamless access.
- 💬 **Real-Time Updates** – Instantly reflect menu changes to customers.
- 📱 **Responsive Design** – Works beautifully on mobile, tablet, and desktop.
- 🔐 **Auth0 Integration** – Secure login and user management for hotel owners.
- 💻 **Modern UI/UX** – Jeton-style, smooth animations, professional layout.
- 🆓 **Free Deployment** – Hosted using GitHub + Netlify with Firebase backend.

---

## 🛠️ Tech Stack

- **Tailwind CSS**
- **JavaScript (Vanilla)**
- **Firebase (Realtime Database)**
- **Auth0 (Authentication)**
- **GitHub + Netlify (Hosting)**
